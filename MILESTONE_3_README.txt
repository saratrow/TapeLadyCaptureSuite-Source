TAPE LADY CAPTURE SUITE — MILESTONE 3

What is new
- Persistent tape queue
- Load a queued tape with a double-click
- Tape notes
- Automatic completion after a successful recording
- Capture history with Play File and Open Folder
- Save folder and preferred devices remembered
- Free disk-space display and low-space warning color
- Queue/history auto-saved after every change
- Existing Milestone 2 preview and FFmpeg recording engine preserved

Open TapeLadyCaptureSuite.csproj in Visual Studio, then Build > Rebuild Solution.
Install FFmpeg from the button in the application before your first recording.

State is stored in:
%LOCALAPPDATA%\TapeLady\CaptureSuite\state.json
